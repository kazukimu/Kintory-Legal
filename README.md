# Kintory Legal

Kintory の利用規約、プライバシーポリシー、サポート情報を GitHub Pages で公開するリポジトリです。

公開URL: `https://kazukimu.github.io/Kintory-Legal/`

## 運用

- 規約を変更したら、施行日と変更内容を更新してください。
- 新しい SDK、広告、分析、クラウド同期、アカウント、課金を導入する前に、プライバシーポリシーと App Store Connect の App Privacy を見直してください。
- 問い合わせフォームの公開設定と送信先は、Google Forms 側で管理します。
